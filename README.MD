# Конспект: Source Control в VS Code (Ctrl + Shift + G)

Вкладка Source Control предназначена для интеграции с системами контроля версий (чаще всего **Git**). Она позволяет управлять изменениями в коде прямо из редактора.

## Основные зоны интерфейса
* **Поле ввода (Commit Message):** Окно для текста, описывающего изменения. Кнопка **Commit** сохраняет эти изменения локально.
* **Раздел CHANGES (Изменения):** Список файлов, которые были изменены, созданы или удалены со времени последнего коммита.
* **Раздел STAGED CHANGES (Индексированные изменения):** Файлы, подготовленные для включения в следующий коммит (после нажатия на "+").

## Индикаторы состояния файлов (буквы рядом с именем)
* **U (Untracked):** Новый файл, который еще не отслеживается Git.
* **M (Modified):** Существующий файл, в который были внесены изменения.
* **D (Deleted):** Файл был удален.
* **A (Added):** Файл добавлен в индекс (Staged) и готов к коммиту.

## Главные операции (Иконки при наведении)
* **Плюс (+):** Stage Changes — добавить файл в индекс (подготовить к сохранению).
* **Минус (-):** Unstage Changes — убрать файл из индекса.
* **Стрелка поворота (⟲):** Discard Changes — отменить все незакоммиченные изменения в файле (вернуть к исходному состоянию).

## Панель дополнительных действий (Три точки «...»)
* **Pull / Push:** Скачивание изменений из удаленного репозитория (GitHub/GitLab) и отправка своего кода в сеть.
* **Branch:** Создание, переключение и слияние веток проекта.
* **Stash:** Временное сохранение текущих недоделанных изменений без создания официального коммита.
